Section 1: Fundamental Matrix Estimation From Point Correspondences

In this section I use the 2D data points from images 1 and 2 in aata set 1. The linear least-squares eight-point algorithm was implemented to estimate the fundamental matrix F between two image views. First, coordinates from points1 and points2 are extracted and normalized to inhomogeneous form if necessary. A N X 9 design matrix A is constructed where each row represents the epipolar constraint equation corresponding to a point match (x2x1, x2y1, x2, y2x1, y2y1, y2, x1, y1, 1). Using Singular Value Decomposition (SVD), the homogeneous linear system Af = 0 is solved in the least-squares sense, taking the right singular vector corresponding to the smallest singular value as the initial solution for F. Finally, to satisfy the epipolar geometry constraint that det(F) = 0, a secondary SVD is applied directly to the 3 X 3 matrix F to zero out its smallest singular value, yielding the final rank-constrained refined fundamental matrix F refinded.

The function lls_eight_point_alg used to calulate the fundamental matrix is shown below:

				    N = points1.shape[0]
				
				    if points1.shape[1] == 2:
				        x1, y1 = points1[:, 0], points1[:, 1]
				
				    else:
				        x1 = points1[:, 0] / points1[:, 2]
				        y1 = points1[:, 1] / points1[:, 2]

				        y1,
				        np.ones(N)

Next, I will determine the fundamental matrix using normalized eight point algorithm. The fundamental difference between this algorithm and standard linear least-squares eight point algorithm is in data conditioning before algebrai minimiation takes place.

Standard algorithm builds the constraint matrix A from raw image pixel cordinates (x, y) and sets up the homogenous function Af = 0. The problem with this approach is that image cordinates generally span large pixel values, hundreds or thousands of pixels per image, which results in large values of terms like x1x2 compared to linears terms, x1, and contant terms, 1. This creates massive range of magnitudes in the matrix A making the matrix ill-conditioned. Due to this variance in the range of values in the matrix the unnormalized fundamental matrix is highly sensitive to noise and yields poor epipolar lines.

The normalized eight point algorithm applies pre-processing cordinate transformation matrix (T1 and T2) to both image point sets before running the eight-point algorithm. It does two main things. 1.Shifts the point coordinates so that their mean (centroid) is at the origin (0,0). 2. Scales the coordinates isotropically so that the average root-mean-square (RMS) distance of the points from the origin is equal to sqrt(2) (meaning points typically lie within a radius of sqrt(2). Additionally, after solving for the fundamental matrix, the matrix is transformed back to the original pixel cordinate space using the similarity transforms drastically improving numerical conditioning of the constraint matrix A. It ensures that all equations contribute equally to the least-squares minimization, resulting in a robust, highly accurate fundamental matrix that is invariant to coordinate choices. The algorithm implementation is shown in the code below.

				    def to_inhomogenous(pts):
				        if pts.shape[1] == 3:
				            return pts[:, :2] / pts[:, 2:3]
				        return pts[:, :2]
				
				    pts1_inh = to_inhomogenous(points1)

				        [0, scale2, -scale2 * mean2[1]],
				        [0, 0, 1]

The normalized eight point algorithm computes the fundamental matrix from matching point coordinates by first converting homogenous inputs into inhomogenous 2D coordinates. It then applies the Hartley normalization to both sets of coordinates seperately, shifting their centroids to the origin and scaling them so the root mean square distance is equal to sqrt(2). This pre-processing prevents large coordinate values from ill conditioning the linear system. Once the coordinates are normalized, the algorithm constructs a N X 9 matrix A representing the epipolar constraints and solves the homogenous system Af = 0 using SVD taking the right singular vector associated with the smallest singular value as the initial fundamental matrix estimate. To satisfy the essential algebraic requirement that a valid fundamental matrix must have a determinant of zero, a secondary SVD is performed on the estimate to zero out its smallest singular value. Finally, the resulting matrix is denormalized back to the original image coordinate space using the inverse similarity transforms defined by the normalization matrices, yielding the final refined fundamental matrix. def extract_harris_features(img, max_corners=1000, threshold=0.01):
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY).astype(np.float32)
    corners = cv2.cornerHarris(gray, blockSize=2, ksize=3, k=0.04)

    dst = cv2.dilate(corners, None)
    ret = dst > threshold * dst.max()
    y_idxs, x_idxs = np.where(ret)
    pts = np.stack((x_idxs, y_idxs), axis=-1)

    if len(pts) > max_corners:
        scores = dst[y_idxs, x_idxs]
        top_indices = np.argsort(scores)[::-1][:max_corners]
        pts = pts[top_indices]
    return pts

def extract_descriptors(img, pts):
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY).astype(np.float32)
    h, w = gray.shape
    descriptors = []
    valid_pts = []
    
    for pt in pts:
        x, y = int(pt[0]), int(pt[1])

        if x - 20 < 0 or x + 20 >= w or y - 20 < 0 or y + 20 >= h:
            continue

        patch_40 = gray[y-20:y+20, x-20:x+20]

            norm_patch = patch_8 - mean
            
        descriptors.append(norm_patch.flatten())
        valid_pts.append([x, y])
        
    return np.array(valid_pts), np.array(descriptors)

def match_features_lowe(desc1, desc2, pts1, pts2, ratio_thresh=0.75):
    matches = []

    dist_matrix = np.linalg.norm(desc1[:, np.newaxis, :] - desc2[np.newaxis, :, :], axis=2)
    
    for i, row in enumerate(dist_matrix):
        sorted_idxs = np.argsort(row)
        if len(sorted_idxs) < 2:
            continue
        nn1, nn2 = sorted_idxs[0], sorted_idxs[1]
        if row[nn1] < ratio_thresh * row[nn2]:
            matches.append((pts1[i], pts2[nn1]))
            
    if len(matches) == 0:
        return np.empty((0, 2)), np.empty((0, 2))
    
    matches = np.array(matches)
    return matches[:, 0], matches[:, 1]

def computeH(im1_pts, im2_pts):
    def norm_T(p):
        c = p.mean(axis=0)
        s = np.sqrt(2) / np.mean(np.linalg.norm(p - c, axis=1))
        return np.array([[s, 0, -s * c[0]],
                         [0, s, -s * c[1]],
                         [0, 0, 1]])

    T1, T2 = norm_T(im1_pts), norm_T(im2_pts)
    p1 = (T1 @ np.c_[im1_pts, np.ones(len(im1_pts))].T).T[:, :2]
    p2 = (T2 @ np.c_[im2_pts, np.ones(len(im2_pts))].T).T[:, :2]

    A = []
    for (x, y), (xp, yp) in zip(p1, p2):
        A.append([-x, -y, -1, 0, 0, 0, x * xp, y * xp, xp])
        A.append([0, 0, 0, -x, -y, -1, x * yp, y * yp, yp])
    _, _, Vt = np.linalg.svd(np.array(A, dtype=np.float64))
    Hn = Vt[-1].reshape(3, 3)

    H = np.linalg.inv(T2) @ Hn @ T1
    return H / H[2, 2]

def ransac_homography(pts1, pts2, num_iterations=1500, threshold=4.0):
    num_pts = len(pts1)
    if num_pts < 4:
        raise ValueError("Not enough matching points found to run RANSAC (need >= 4).")
    
    best_H = None
    max_inliers = -1
    pts1_h = np.hstack([pts1, np.ones((num_pts, 1))])
    
    for _ in range(num_iterations):
        idx = np.random.choice(num_pts, 4, replace=False)
        H_sample = computeH(pts1[idx], pts2[idx])
        
        projected = (H_sample @ pts1_h.T).T
        eps = 1e-8
        projected[:, :2] /= (projected[:, 2:3] + eps)
        
        errors = np.linalg.norm(projected[:, :2] - pts2, axis=1)
        inlier_mask = errors < threshold
        num_inliers = np.sum(inlier_mask)
        
        if num_inliers > max_inliers:
            max_inliers = num_inliers
            best_H = H_sample

    if max_inliers >= 4:
        projected = (best_H @ pts1_h.T).T
        projected[:, :2] /= (projected[:, 2:3] + 1e-8)
        final_mask = np.linalg.norm(projected[:, :2] - pts2, axis=1) < threshold
        if np.sum(final_mask) >= 4:
            best_H = computeH(pts1[final_mask], pts2[final_mask])
            
    print(f"RANSAC finished with {max_inliers} inliers out of {num_pts} matches.")
    return best_H

def warpImageBilinearWithCanvas(im, H_global, out_w, out_h):

    mask = np.ones((h, w), dtype=np.uint8) * 255

    alpha_src = dist / (dist.max() + 1e-5)

    X_out, Y_out = np.meshgrid(np.arange(out_w), np.arange(out_h))
    coords_out = np.vstack((X_out.ravel(), Y_out.ravel(), np.ones(out_w * out_h)))

               wc * ch[y1c, x0c] + wd * ch[y1c, x1c])
        val[~valid] = 0
        warped[:, :, c] = val

    alpha = (wa * alpha_src[y0c, x0c] + wb * alpha_src[y0c, x1c] +
             wc * alpha_src[y1c, x0c] + wd * alpha_src[y1c, x1c])
    alpha[~valid] = 0
    return warped, alpha

acc_rgb = np.zeros((out_h, out_w, 3), dtype=np.float64)
acc_alpha = np.zeros((out_h, out_w), dtype=np.float64)

for img, H in zip(images, homographies):
    warped, alpha = warpImageBilinearWithCanvas(img, T @ H, out_w, out_h)
    acc_rgb += warped * alpha[:, :, np.newaxis]
    acc_alpha += alpha

acc_alpha[acc_alpha == 0] = 1.0
mosaic = np.clip(acc_rgb / acc_alpha[:, :, np.newaxis], 0, 255).astype(np.uint8)

plt.figure(figsize=(12, 6))
plt.imshow(mosaic)
plt.title("Automated RANSAC Stitched Image Mosaic")
plt.axis("off")
plt.show()

The code automatically picks correspondance points in the input images and matches them to similar points on the reference image. Firstly, Harris corner detection is used to detect prominent interest points by converting the images to greyscale and identifiying regions where the gradient changes sharply in more than one direction.

For each of these corners, a 40x40 pixel neighborhood is extracted, resized to a 8x8 matrix and normalized to ensure invariance to lighting and contrast changes.

Next, the features are matched between images by calculating the eucleadean distance between the normalized matrices. For each point two nearest neighbors are picked and tested with Lowe's ratio test, rejecting ambigous matches where multiple targets look similar.

Automated matching inevitably yields incorrect matches. The RANSAC (Random Sample Consensus) samples random subsets of 4 point correspondences, computes a trial homography matrix using, and counts how many total matching points agree with that model within a pixel error threshold. The model with the highest number of consistent inliers is selected as the optimal homography.

Comparing the results of the manual mosaic and the automated mosaic it is clear that manual mosaic produced better results since I picked points at distinct sharp corners where there were antural boundaries, such as roof and trees or the edge of a building and also spaced the correspondance points further apart from each other to ensure sufficient overlap between images.

Harris corner detector concentrated matches on a very small, localized cluster (mostly clustered on the distant apartment building facade shown in the top match visualizations), leaving large portions of the image unconstrained. Simple normalized intensity patches combined with Lowe's ratio test are sensitive to repetitive textures (like windows on high-rise apartment blocks). This causes incorrect cross-matches that slip past the RANSAC threshold if the initial point pool lacks good geometric spread. When point correspondences are clustered in a small region rather than spread across the image plane, the resulting homography matrix becomes ill-conditioned. Small pixel noise leads to massive angular distortions when projected across the wider canvas

In order to improve the results for the automated pipeline, instead of the Harris corner detection we can use other corner detection methods that space out the correspondance points evenly throughout the image. Lowering the RANSAC reprojection error threshold can further help improve the results.
