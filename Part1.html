Section 1: Fundamental Matrix Estimation From Point Correspondences

In this section I use the 2D data points from a pair of images and the linear least-squares eight-point algorithm to estimate the fundamental matrix F for two the images. First, coordinates from image 1 and image 2 are extracted and normalized to inhomogeneous form if necessary. A N X 9 design matrix A is constructed where each row represents the epipolar constraint equation corresponding to a point match (x2x1, x2y1, x2, y2x1, y2y1, y2, x1, y1, 1). Using Singular Value Decomposition (SVD), the homogeneous linear system $Af = 0$ is solved in the least-squares sense, taking the right singular vector corresponding to the smallest singular value as the initial solution for F. Finally, to satisfy the epipolar geometry constraint det(F) = 0, a secondary SVD is applied directly to the 3 X 3 matrix F to zero out its smallest singular value, yielding the final rank-constrained refined fundamental matrix F refinded.

The function lls_eight_point_alg used to calulate the fundamental matrix is shown below:


					def lls_eight_point_alg(points1, points2):
				    N = points1.shape[0]
				
				    if points1.shape[1] == 2:
				        x1, y1 = points1[:, 0], points1[:, 1]
				
				    else:
				        x1 = points1[:, 0] / points1[:, 2]
				        y1 = points1[:, 1] / points1[:, 2]
				
				    if points2.shape[1] == 2:
				        x2, y2 = points2[:, 0], points2[:, 1]
				
				    else: 
				        x2 = points2[:, 0] / points2[:, 2]
				        y2 = points2[:, 1] / points2[:, 2]
				
				    A = np.column_stack([
				        x2 * x1,
				        x2 * y1,
				        x2,
				        y2 * x1,
				        y2 * y1,
				        y2,
				        x1,
				        y1,
				        np.ones(N)
				    ])
				
				    U, S, Vt = np.linalg.svd(A)
				    f = Vt[-1, :]
				    F = f.reshape(3, 3)
				    U_f, S_f, Vt_f = np.linalg.svd(F)
				    S_f[-1] = 0.0
				    F_refined = U_f @ np.diag(S_f) @ Vt_f
				
				    return F_refined
				
				F_matrix = lls_eight_point_alg(points1, points2)
				
				np.set_printoptions(precision=7, suppress=True)
				
				print("Estimated Fundamental Matrix (F_refined):")
				print(F_matrix)

Next, I will determine the fundamental matrix using normalized eight point algorithm. The fundamental difference between this algorithm and standard linear least-squares eight point algorithm is in data conditioning before algebraic minimization takes place.

The algorithm builds the constraint matrix A from raw image pixel cordinates (x, y) and sets up the homogenous function $Af = 0$. The problem with this approach is that image cordinates generally span large pixel values, hundreds or thousands of pixels per image, which results in large values of terms like x1x2 compared to linear terms, x1, and contant terms, 1. This creates massive range of magnitudes in the matrix A making the matrix ill-conditioned. Due to this variance in the range of values in the matrix the unnormalized fundamental matrix is highly sensitive to noise and yields poor epipolar lines.

The normalized eight point algorithm applies pre-processing cordinate transformation matrix (T1 and T2) to both image point sets before running the eight-point algorithm. It does two main things. 1.Shifts the point coordinates so that their mean (centroid) is at the origin (0,0). 2. Scales the coordinates isotropically so that the average root-mean-square (RMS) distance of the points from the origin is equal to sqrt(2) (meaning points typically lie within a radius of $$sqrt(2)$$ Additionally, after solving for the fundamental matrix, the matrix is transformed back to the original pixel cordinate space using the similarity transforms drastically improving numerical conditioning of the constraint matrix A. It ensures that all equations contribute equally to the least-squares minimization, resulting in a robust, highly accurate fundamental matrix that is invariant to coordinate choices. The algorithm implementation is shown in the code below.

				
				def normalized_eight_point_alg(points1, points2):
				    
				    def to_inhomogenous(pts):
				        if pts.shape[1] == 3:
				            return pts[:, :2] / pts[:, 2:3]
				        return pts[:, :2]
				
				    pts1_inh = to_inhomogenous(points1)
				    pts2_inh = to_inhomogenous(points2)
				
				    N = pts1_inh.shape[0]
				
				    mean1 = np.mean(pts1_inh, axis=0)
				    max_dist1 = np.max(np.sqrt(np.sum((pts1_inh - mean1)**2, axis=1)))
				    scale1 = np.sqrt(2) / max_dist1 if max_dist1 > 0 else 1.0
				
				    T1 = np.array([
				        [scale1, 0, -scale1 * mean1[0]],
				        [0, scale1, -scale1 * mean1[1]],
				        [0, 0, 1]
				    ])
				
				    pts1_hom = np.column_stack([pts1_inh, np.ones(N)])
				    pts1_norm = (T1 @ pts1_hom.T).T
				
				    mean2 = np.mean(pts2_inh, axis=0)
				    max_dist2 = np.max(np.sqrt(np.sum((pts2_inh - mean2)**2, axis=1)))
				    scale2 = np.sqrt(2) / max_dist2 if max_dist2 > 0 else 1.0
				
				    T2 = np.array([
				        [scale2, 0, -scale2 * mean2[0]],
				        [0, scale2, -scale2 * mean2[1]],
				        [0, 0, 1]
				    ])
				
				    pts2_hom = np.column_stack([pts2_inh, np.ones(N)])
				    pts2_norm = (T2 @ pts2_hom.T).T
				
				    x1_n, y1_n = pts1_norm[:, 0], pts1_norm[:, 1]
				    x2_n, y2_n = pts2_norm[:, 0], pts2_norm[:, 1]
				
				    A = np.column_stack([
				        x2_n * x1_n,
				        x2_n * y1_n,
				        x2_n,
				        y2_n * x1_n,
				        y2_n * y1_n,
				        y2_n,
				        x1_n,
				        y1_n,
				        np.ones(N)
				    ])
				
				    _, _, Vt = np.linalg.svd(A)
				    f = Vt[-1, :]
				    F_norm = f.reshape(3, 3)
				
				    U_f, S_f, Vt_f = np.linalg.svd(F_norm)
				    S_f[-1] = 0.0
				    F_norm_refined = U_f @ np.diag(S_f) @ Vt_f
				
				    F = T2.T @ F_norm_refined @ T1
				
				    return F

The normalized eight point algorithm computes the fundamental matrix from matching point coordinates by first converting homogenous inputs into inhomogenous 2D coordinates. It then applies the Hartley normalization to both sets of coordinates seperately, shifting their centroids to the origin and scaling them so the root mean square distance is equal to $$sqrt(2)$$ This pre-processing prevents large coordinate values from ill conditioning the linear system. Once the coordinates are normalized, the algorithm constructs a N X 9 matrix A representing the epipolar constraints and solves the homogenous system $$Af = 0$$ Using SVD taking the right singular vector associated with the smallest singular value as the initial fundamental matrix estimate. To satisfy the essential algebraic requirement that a valid fundamental matrix must have a determinant of zero, a secondary SVD is performed on the estimate to zero out its smallest singular value. Finally, the resulting matrix is denormalized back to the original image coordinate space using the inverse similarity transforms defined by the normalization matrices, yielding the final refined fundamental matrix. Epipolar lines are calculated using the 


				def compute_distance_to_epipolar_lines(points1, points2, F):
			        if points1.shape[1] == 2:
			            pts1_hom = np.column_stack([points1, np.ones(points1.shape[0])])
			        else:
			            pts1_hom = points1
			    
			        if points2.shape[1] == 2:
			            pts2_hom = np.column_stack([points2, np.ones(points2.shape[0])])
			        else:
			            pts2_hom = points2
			    
			        lines = (F.T @ pts2_hom.T).T
			    
			        numerator = np.abs(np.sum(pts1_hom * lines, axis=1))
			        denominator = np.sqrt(lines[:, 0]**2 + lines[:, 1]**2)
			        distances = numerator / denominator
			        average_distance = np.mean(distances)
			
			        return average_distance

The function compute_distance_to_epipolar_lines calculates the geometric reprojection error by finding the perpendicular distance from each point in the first image to its corresponding epipolar line. Mathematically, given a homogeneous point $${x} = [x, y, 1]^T$$ in the first image and its matching point $${x}'$$ in the second image, the epipolar line equation $${l} = [a, b, c]^T$$ in the first image is determined by the transposed fundamental matrix:

$${l} = F^T \f{x}'$$

For a line defined by $$ax + by + c = 0$$, the perpendicular distance $d$ from a homogeneous point $$f({x}) = [x, y, 1]^T$$ to this line is given by the algebraic point-line distance formula:

$$d = \frac{|\mathbf{x}^T \mathbf{l}|}{\sqrt{a^2 + b^2}}$$

Next I implement the Hartley Ractification algortithem that is used to warp a pair of images such that their corresponding epipolar lines are parallel to the horontal axis simplifying the correspondance searches to a horizontal 1D scan instead of a 2D scan.

The algorithm begins by extracting the epipoles from the fundamental matrix calculated in the previous section. In the compute_epipole function, the null vector of $$F^T$$ is isolated using SVD satisfying the epipolar constraint $$F^Te2 = 0$$ for the second image's epipole e2.

Next, the compute_H function constructs three geometric trnsformations.

1. A translational matrix that shifts the image center to origin.

2. A rotation matrix that aligns the translated epipole with the horiontal axis.

3. A projectve transformation matrix that sends the epipole to infinity.

Combining these three steps yields that rectifying homography H = T^-1GRT for a given image and epipole. To ensure the pair of images is rectified in a matching, compatible way, compute_matching_homographies computes the second image's homography $H_2 = \text{compute\_H}(\mathbf{e}_2, \text{im}_2)$ and establishes an initial transformation $H_0 = H_2 M$. Here, $M$ is the mapping matrix defined by $M = [\mathbf{e}_2]_\times F + \mathbf{e}_2 \mathbf{v}^T$, with $[\mathbf{e}_2]_\times$ representing the skew-symmetric cross-product matrix of $\mathbf{e}_2$ and $\mathbf{v}^T = [1, 1, 1]$. Because mapping the epipole to infinity introduces projective distortion, an additional affine correction homography $H_A$ is introduced to minimize image skew and ensure optimal alignment. The parameters of $HA$ are solved via linear least squares ($\text{np.linalg.lstsq}$) by minimizing the squared distance between the transformed feature points. The final matching homography for the first image is then given by $H_1 = H_A H_2 M$, completing the geometric rectification pipeline for both images

The algorithm and the resulting image is shown below.


				def compute_epipole(F):
			    _, _, Vt = np.linalg.svd(F.T)
			    e = Vt[-1, :]
			
			    if abs(e[2]) > 1e-10:
			        e = e / e[2]
			    else:
			        e = e / np.linalg.norm(e)
			
			    return e

				def compute_H(e, im):
				height, width = im.shape[0], im.shape[1]
			
				# Translate image center to the origin
				T = np.array([
					[1, 0, -width / 2.0],
					[0, 1, -height / 2.0],
					[0, 0, 1]
				])
			
				e_translated = T @ e
				e1, e2 = e_translated[0], e_translated[1]
			
				# Rotate epipole onto the x-axis
				alpha = 1 if e1 >= 0 else -1
				norm_e = np.sqrt(e1**2 + e2**2)
			
				if norm_e > 1e-10:
					c1 = alpha * (e1 / norm_e)
					c2 = alpha * (e2 / norm_e)
				else:
					c1, c2 = 1.0, 0.0
			
				R = np.array([
					[c1, c2, 0],
					[-c2, c1, 0],
					[0, 0, 1]
				])
			
				e_rotated = R @ e_translated
				f = e_rotated[0]
			
				# Send the epipole to infinity
				if abs(f) > 1e-10:
					G = np.array([
						[1, 0, 0],
						[0, 1, 0],
						[-1.0 / f, 0, 1]
					])
				else:
					G = np.eye(3)
			
				T_inv = np.linalg.inv(T)
				H = T_inv @ G @ R @ T
			
				return H

				def compute_matching_homographies(e2, F, im2, points1, points2):
			    H2 = compute_H(e2, im2)
			
			    e_x = np.array([
			        [0, -e2[2], e2[1]],
			        [e2[2], 0, -e2[0]],
			        [-e2[1], e2[0], 0]
			    ])
			
			    v_T = np.array([1, 1, 1])
			    M = e_x @ F + np.outer(e2, v_T)
			
			    def to_homogeneous(pts):
			        if pts.shape[1] == 3:
			            pts = pts[:, :2] / pts[:, 2:3]
			        else:
			            pts = pts[:, :2]
			        return np.column_stack([pts, np.ones(pts.shape[0])])
			
			    pts1_hom = to_homogeneous(points1)
			    pts2_hom = to_homogeneous(points2)
			
			    # H0 maps image 1 into the rectified frame (up to the affine H_A)
			    H0 = H2 @ M
			
			    # FIX: fit H_A on the points AFTER H0 / H2 are applied
			    p1_hat = (H0 @ pts1_hom.T).T
			    p1_hat = p1_hat / p1_hat[:, 2:3]
			
			    p2_hat = (H2 @ pts2_hom.T).T
			    p2_hat = p2_hat / p2_hat[:, 2:3]
			
			    # Solve  p1_hat @ a = x-coordinates of p2_hat  (least squares)
			    a, _, _, _ = np.linalg.lstsq(p1_hat, p2_hat[:, 0], rcond=None)
			
			    H_A = np.array([
			        [a[0], a[1], a[2]],
			        [0,    1,    0],
			        [0,    0,    1]
			    ])
			
			    H1 = H_A @ H0
			
			    return H1, H2

Next, I implement the Tomasi and Kanade Factorization method to perform affine structure from motion reconstruction from 2D point corresponences across two images.

The code first converts input points to inhomogeneous coordinates and centers them by subtracting the mean centroid for each image view. Next, it stacks these centered coordinates into a $4 \times N$ measurement matrix, performs Singular Value Decomposition, and enforces a rank-3 constraint by retaining only the top three singular values and components to factor the matrices into motion and structure matrices. Finally, it iterates through dataset folders to execute the factorization and renders side-by-side 3D scatter plots comparing the reconstructed structure against ground-truth 3D coordinates. The code for the factorization method and the 3D plots for two sets of data points are shown below.


				def factorization_method(points_im1, points_im2):
			    def to_inhomogeneous(pts):
			        if pts.shape[1] == 3:
			            return pts[:, :2] / pts[:, 2:3]
			        return pts[:, :2]
			
			    p1 = to_inhomogeneous(points_im1)
			    p2 = to_inhomogeneous(points_im2)
			
			    # Center each image's points at their centroid
			    p1_centered = p1 - np.mean(p1, axis=0)
			    p2_centered = p2 - np.mean(p2, axis=0)
			
			    # Measurement matrix: 4 x N
			    W = np.vstack([p1_centered.T, p2_centered.T])
			
			    # Economy SVD avoids building an N x N matrix
			    U, S, Vt = np.linalg.svd(W, full_matrices=False)
			
			    U_3 = U[:, :3]
			    sqrt_S3 = np.diag(np.sqrt(S[:3]))
			    Vt_3 = Vt[:3, :]
			
			    motion = U_3 @ sqrt_S3        # 4 x 3
			    structure = sqrt_S3 @ Vt_3    # 3 x N
			
			    return structure, motion

the reconstructed 3D point cloud from the factorization method preserves the exact geometric shape and relative spatial layout of the ground truth, but appears rotated, translated (centered at the origin due to mean-subtraction), and scaled differently.

If we insert any invertible $3 \times 3$ affine transformation matrix $A$ (and its inverse $A^{-1}$) between the motion and structure matrices such that:$$\text{Motion}_{\text{new}} = \text{Motion} \cdot A \quad \text{and} \quad \text{Structure}_{\text{new}} = A^{-1} \cdot \text{Structure}$$. The product remains unchanged ($\text{Motion}_{\text{new}} \cdot \text{Structure}_{\text{new}} = \text{Motion} \cdot \text{Structure} = W$). Therefore, the measurements in the image plane cannot distinguish between the true 3D structure and an affinely transformed version of it.

At the very beginning of the algorithm, the 2D point coordinates are centered by subtracting their mean centroids. Because absolute translational depth with respect to the camera coordinate origin is lost during orthographic/affine projection, the reconstructed 3D points are automatically centered around the origin $(0,0,0)$.

Without known camera calibration parameters or absolute depth measurements, Tomasi-Kanade factorization can only recover the 3D structure up to an arbitrary 3D linear transformation (or scaled Euclidean reconstruction), which explains why the axes lengths and overall scale differ between your factorization plot and the ground truth.
